# Image credits

The website uses four photographs from Unsplash, free to use for commercial
purposes under the Unsplash License (https://unsplash.com/license). No
attribution is required, but the photographers are credited here.

These photographs show third-party solar plants and are used for illustration
only. They are not NOORLUME projects and must not be captioned as such.

| Where used | Subject | Photographer | Source page |
| --- | --- | --- | --- |
| Home page hero | Utility-scale solar plant, Dunhuang, China | darmau | https://unsplash.com/photos/an-aerial-view-of-a-large-solar-farm-Y5j57HvzuZg |
| Home "Ground-mounted solar PV" card | Solar plant in a desert landscape | Priamo Mendez | https://unsplash.com/photos/a-large-field-of-solar-panels-in-the-desert-E4XEBPEkgUs |

The images are loaded from Unsplash's image servers. Each has a fallback: if a
photo cannot be loaded, the matching line-art drawing is shown instead.

To use your own photographs, put the files in `public/photos/` and change the
entries in the `photos` object in `components/ui.tsx`. Demonstration project
entries deliberately keep line art, so that no real plant is presented as a
NOORLUME project.
